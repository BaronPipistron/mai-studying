# Отчёт: Добыча корпуса (Habr + Stack Overflow RU)

## 1) Источники и метод
- **Habr (RU)** — https://habr.com/ru/  
- **Stack Overflow на русском** — https://ru.stackoverflow.com/  

Для сбора корпуса документов использовался python скрипт - он обходил заданное количество статей на Хабр и вопросов со StackOverflow, сохранял raw HTML и извлекал из них уже чистый текст (заголовок + основной контент). Для извлечения текста использовались CSS-селекторы. Также учитывался `robots.txt`, между запросами была паузы, чтобы избежать блокировки и не дудосить сайты


## 2) Статистика по источникам

- Средний размер текста: **~66.8 KB/doc**
- Число слов в документе (min/p50/p90/p99/max): **45 / 4213 / 10447 / 21825 / 40205**

## 3) Выводы по корпусу
- **Habr** - длинные статьи, содержащие большое количество слов (медиана ~4.2K)
- **Stack Overflow RU** на текущем этапе брался только как **текст вопроса** (без ответов/комментариев), отсюда малые объёмы (медиана ~145 слов). При добавлении ответов объём и полезность корпуса заметно вырастут

## 4) Поисковые системы и примеры запросов
- **Встроенные поиски**: Habr, Stack Overflow RU
- **Веб-поиск c ограничением сайта**: `site:habr.com`, `site:ru.stackoverflow.com`.

Примеры:
- `site:habr.com "обратный индекс" поиск`
- `site:habr.com микросервисы паттерны`
- `site:ru.stackoverflow.com "регулярное выражение" python`
- `site:ru.stackoverflow.com "индексация" elasticsearch`

**Недостатки результатов:** на StackOverflow встречаются вопросы без полноценных ответов по длинным запросам, шаблоны поиска довольтно вариативные, не всегда получаем релевантные результаты, смешиваются листинги и статьи
